# Strings (2026-11-20)

Short strings (names, keys, literal arguments; up to 64 characters, at most 4096 of them) are cached as Java string global refs, so a repeat costs a dictionary lookup instead of NewString and DeleteLocalRef. Same machine as `2026-11-20.md`.
